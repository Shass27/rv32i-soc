# RV32I CPU Control Signals Documentation

| Signal | Width | Direction | From → To | Description |
|---|---|---|---|---|
| clk | 1 | Input | Top → All | Global clock signal used to synchronize all sequential modules. |
| reset | 1 | Input | Top → All | Synchronous reset signal; initializes the processor state and resets the PC. |
| pc | 32 | Output | IF → ID, EX | Current Program Counter (PC) value. |
| instr | 32 | Output | IF → ID | 32-bit instruction fetched from instruction memory. |
| branch_target | 32 | Input | ID → IF | Target address computed for branch instructions (PC + immediate). |
| jump_target | 32 | Input | ID → IF | Target address computed for JAL instructions. |
| branch_taken | 1 | Input | ID → IF | Indicates whether the branch condition is satisfied. |
| jump | 1 | Input | ID → IF | Indicates a jump instruction (JAL). |
| rs1 | 5 | Output | ID → EX | Source register 1 address (instr[19:15]). |
| rs2 | 5 | Output | ID → EX | Source register 2 address (instr[24:20]). |
| rd | 5 | Output | ID → EX | Destination register address (instr[11:7]). |
| funct3 | 3 | Output | ID → EX | Function field used for ALU operation decoding. |
| funct7 | 7 | Output | ID → EX | Additional function field to distinguish ALU operations. |
| imm | 32 | Output | ID → EX, IF | Sign-extended immediate generated by the Immediate Generator. |
| RegWrite | 1 | Output | ID → EX | Enables writing to the destination register. |
| ALUSrc | 1 | Output | ID → EX | Selects ALU operand B (0=rs2, 1=Immediate). |
| ALUOp | 2 | Output | ID → EX | High-level ALU operation code for ALU Control. |
| MemRead | 1 | Output | ID → MEM | Enables Data Memory read. |
| MemWrite | 1 | Output | ID → MEM | Enables Data Memory write. |
| MemToReg | 1 | Output | ID → MEM/WB | Selects writeback source (ALU result or memory data). |
| alu_result | 32 | Output | EX → MEM, ID | Result produced by the ALU. |
| alu_zero | 1 | Output | EX → ID | Zero flag used for branch comparison. |
| rs2_data | 32 | Output | EX → MEM | Register value forwarded for store instructions. |
| wb_data | 32 | Input | MEM/WB → EX | Data written back into the register file. |
| mem_rdata | 32 | Output | MEM → MEM/WB | Data read from Data Memory. |
| mem_addr | 32 | Input | EX → MEM | Memory address generated by the ALU. |
| mem_wdata | 32 | Input | EX → MEM | Data written into Data Memory. |
| wb_sel | 1 | Input | ID → MEM/WB | Writeback multiplexer select signal. |
| rd_wb | 5 | Input | ID → MEM/WB | Destination register index used during writeback. |

| Value | Meaning |
|---|---|
| 0 | Second operand = rs2 |
| 1 | Second operand = Immediate |

| Value | Meaning |
|---|---|
| 00 | Addition (Load/Store) |
| 01 | Subtraction (BEQ) |
| 10 | R-type / I-type (decoded using funct3 & funct7) |
| 11 | Reserved / Jump (implementation dependent) |

This document describes the datapath and control signals used in the RV32I single-cycle processor.
