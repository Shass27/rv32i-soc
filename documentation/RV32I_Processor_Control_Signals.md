# RV32I Processor Control Signals Documentation

This document summarizes the major control signals used across the RV32I single-cycle processor modules.

| Signal | Width | Module(s) | Description |
|---|---|---|---|
| clk | 1 | Top | Global clock signal used by all sequential modules. |
| reset | 1 | Top | Resets the processor state and Program Counter. |
| pc | 32 | program_counter | Current Program Counter value. |
| instr | 32 | inst_mem | 32-bit instruction fetched from instruction memory. |
| target | 32 | branch, jump | Computed branch/jump target address. |
| branch | 1 | control_unit | Indicates a branch instruction. |
| branch_taken | 1 | branch | Indicates whether the branch condition is satisfied. |
| jump | 1 | control_unit, jump | Indicates a JAL instruction. |
| jump_ret_addr | 32 | jump | Return address (PC + 4) written to rd during JAL. |
| rs1 | 5 | alu_control | Source register 1 index (instr[19:15]). |
| rs2 | 5 | alu_control | Source register 2 index (instr[24:20]). |
| rd | 5 | alu_control | Destination register index (instr[11:7]). |
| funct3 | 3 | alu_control | Function field used for ALU operation decoding. |
| funct7 | 7 | alu_control | Additional function field to distinguish operations. |
| imm | 32 | immediate_gen | Sign-extended immediate value. |
| RegWrite | 1 | control_unit | Enables register file writeback. |
| ALUSrc | 1 | control_unit | Selects second ALU operand (register/immediate). |
| ALUOp | 2 | control_unit | High-level ALU operation code. |
| ALUControl | 4 | alu_control | Exact ALU operation select (ADD, SUB, AND, OR, XOR, SLL, SRL, SRA, SLT, SLTU, etc.). |
| alu_B | 32 | alu_src_mux | Second ALU operand after ALUSrc multiplexing. |
| A | 32 | alu_module | First ALU operand. |
| B | 32 | alu_module | Second ALU operand. |
| alu_result | 32 | alu_module | Result generated by the ALU. |
| alu_zero | 1 | alu_module | Zero flag used for branch evaluation. |
| MemRead | 1 | control_unit | Enables Data Memory read. |
| MemWrite | 1 | control_unit | Enables Data Memory write. |
| mem_addr | 32 | data_memory | Address supplied to Data Memory. |
| wb_data | 32 | data_memory | It is the final 32-bit value that is written into the Register File. |
| mem_rdata | 32 | data_memory | Data read from Data Memory. |
| MemToReg | 1 | writeback_mux | Selects writeback source (0 = ALU result, 1 = memory data). |
| ReadReg1 | 5 | reg_file | Address of source register 1. |
| ReadReg2 | 5 | reg_file | Address of source register 2 (rs2_data). |
| WriteReg | 5 | reg_file | Destination register address. |
| ReadData1 | 32 | reg_file | Data read from source register 1. |
| ReadData2 | 32 | reg_file | Data read from source register 2. |
| WriteData | 32 | reg_file | Data written back to the register file. |
| stall | 1 | program_counter | Freezes the Program Counter when asserted. |
| i_addr | 32 | inst_mem | Instruction memory address input. |
| o_inst | 32 | inst_mem | Instruction memory output. |
| opcode | 7 | control_unit, alu_control | Opcode field (instr[6:0]) used by the Control Unit and ALU Control to determine the instruction type. |

> Refer the source code for the what the values of the encoding mean.
