# RV32I Processor Control Signals Documentation

This document summarizes the major control signals used across the RV32I single-cycle processor modules.

| Signal | Width | Module(s) | Description |
|---|---|---|---|
| clk | 1 | cpu_top_wb | Global clock used by the register file, PC, and memory. |
| reset | 1 | cpu_top_wb | Resets the processor state and program counter. |
| pc | 32 | program_counter, cpu_top_wb | Current program counter value. |
| instr | 32 | inst_mem, cpu_top_wb | Current 32-bit instruction fetched from instruction memory. |
| target | 32 | cpu_top_wb | Final PC target selected between jump and branch target logic. |
| branch | 1 | control_unit, branch_logic | Asserted for branch instructions. |
| branch_taken | 1 | branch_logic | Indicates whether the branch condition evaluated true. |
| branch_target | 32 | branch_logic, cpu_top_wb | Address produced by a taken branch: `pc + imm`. |
| jump1 | 1 | control_unit, jump_logic, writeback_mux | Asserted for JAL instructions. |
| jump2 | 1 | control_unit, jump_logic, writeback_mux | Asserted for JALR instructions. |
| jump | 1 | cpu_top_wb | Derived OR of `jump1` and `jump2`; higher-priority PC control path. |
| jump_target | 32 | jump_logic, cpu_top_wb | Target computed for JAL/JALR. |
| jump_ret_addr | 32 | jump_logic, writeback_mux | Return address used for the link register (PC + 4). |
| rs1 | 5 | alu_control | Source register 1 index (`instr[19:15]`). |
| rs2 | 5 | alu_control | Source register 2 index (`instr[24:20]`). |
| rd | 5 | alu_control | Destination register index (`instr[11:7]`). |
| funct3 | 3 | alu_control, branch_logic, data_memory | Function field used for ALU operation decoding and memory/branch control. |
| funct7 | 7 | alu_control | Additional function field used to distinguish `SUB`, `SRA`, etc. |
| imm | 32 | imm_gen, cpu_top_wb | Immediate value generated for I/S/B/U/J formats. |
| RegWrite | 1 | control_unit, cpu_top_wb | Enables register file writeback. The register file is driven by `RegWrite_gated = RegWrite & ~stall`, not by `RegWrite` directly. |
| ALUSrc | 1 | control_unit, alu_src_mux | Selects ALU operand `B` between `rs2_data` and `imm`. |
| ALUSrcA | 1 | control_unit, cpu_top_wb | Selects ALU operand `A` between `rs1_data` and `pc` for AUIPC-style behavior. |
| ALUOp | 2 | control_unit, alu_control | High-level ALU opcode: `00` add/auipc, `01` subtract/branch compare, `10` decode by funct3/funct7. `11` (`ALU_JAL`, decodes to ADD) is defined in `alu_control.v` but never emitted by `control_unit.v` (JAL keeps the `00` default). |
| ALUControl | 4 | alu_control, alu_module | Exact ALU operation select: `ADD`, `SUB`, `AND`, `OR`, `XOR`, `SLL`, `SRL`, `SRA`, `SLT`, `SLTU`, `AUIPC_OP`. |
| rs1_data | 32 | reg_file, cpu_top_wb | Data read from source register 1. |
| rs2_data | 32 | reg_file, alu_src_mux, data_memory | Data read from source register 2; also used for stores and ALU input B. |
| alu_A | 32 | cpu_top_wb | Final ALU operand A after muxing. |
| alu_B | 32 | alu_src_mux, cpu_top_wb | Final ALU operand B after muxing. |
| A | 32 | alu_module | First ALU operand input. |
| B | 32 | alu_module | Second ALU operand input. |
| pc (alu_module input) | 32 | alu_module, cpu_top_wb | Extra ALU input, used only by `AUIPC_OP`: `ALU_result = pc + B` (A is ignored). |
| ALU_result | 32 | alu_module, cpu_top_wb | Result generated by the ALU. Also the data address: feeds `data_memory.mem_addr` and `wb_master.i_addr` directly, and the `io_sel` decode. Enters `writeback_mux` on its lowercase port `alu_result`. |
| MemRead | 1 | control_unit, data_memory | Enables data memory read. |
| MemWrite | 1 | control_unit, data_memory | Enables data memory write. |
| mem_addr | 32 | data_memory | `data_memory` port name only; there is no `mem_addr` wire in `cpu_top_wb`. Connected to `ALU_result`. |
| mem_rdata | 32 | cpu_top_wb, writeback_mux | Load data into writeback: `io_sel ? wb_rdat : mem_rdata_local`. `data_memory`'s own output port is also named `mem_rdata` (wired to `mem_rdata_local`). |
| MemToReg | 1 | control_unit, writeback_mux | Selects writeback source: `0` = ALU result, `1` = memory data, and JAL/JALR override to `jump_ret_addr`. |
| wb_data | 32 | writeback_mux, reg_file | Final value written back into the register file. |
| ReadReg1 | 5 | reg_file | Address of source register 1. |
| ReadReg2 | 5 | reg_file | Address of source register 2. |
| WriteReg | 5 | reg_file | Destination register address. |
| ReadData1 | 32 | reg_file | Data read from register file operand 1. |
| ReadData2 | 32 | reg_file | Data read from register file operand 2. |
| WriteData | 32 | reg_file | Data sent to the destination register. |
| stall | 1 | program_counter, cpu_top_wb | `io_sel & ~wb_done`. Freezes the PC (`program_counter.stall`) and, via `RegWrite_gated`, blocks register writeback for the whole bus transaction; released on the `wb_done` pulse. |
| i_addr | 32 | inst_mem | Instruction memory address input. `inst_mem` has parameter `PROG_FILE` (default `"hardware/src/core/if/program.hex"`) and a 4097-word array (`mem[0:4096]`, word-indexed by `i_addr>>2`). |
| o_inst | 32 | inst_mem | Instruction memory output. |
| opcode | 7 | control_unit, alu_control, imm_gen | Opcode field (`instr[6:0]`) used to select instruction type and control behavior. |

## Module parameters and extra ports

| Item | Module | Description |
|---|---|---|
| PROG_FILE | inst_mem | Hex image loaded with `$readmemh`; default `"hardware/src/core/if/program.hex"`. Override to run another image. |
| MEM_SIZE = 4097 | data_memory | Words in the local memory array (`memory[0:MEM_SIZE-1]`), preloaded from `hardware/src/core/mem/data.hex`. |
| TOHOST_ADDR = 32'h000001c0 | data_memory | Address watched by the riscv-tests proxy. A write to it is intercepted (not stored in `memory`): value `1` prints `TOHOST: PASS` and calls `$finish`; any other nonzero value prints `TOHOST: FAIL` and calls `$finish`; `0` is only recorded in the internal `tohost` reg and simulation continues. |
| pc | alu_module | See table above (`AUIPC_OP` only). |

## IO split / stall (cpu_top_wb)

Bottom 64 KB is served by local `data_memory`; any load/store with `ALU_result[31:16] != 0` goes out on Wishbone.

| Signal | Width | Description |
|---|---|---|
| io_sel | 1 | `(MemRead \| MemWrite) & (ALU_result[31:16] != 16'h0000)`. Also masks `MemRead`/`MemWrite` into `data_memory` (`& ~io_sel`). |
| stall | 1 | `io_sel & ~wb_done`. Feeds `program_counter.stall`. |
| RegWrite_gated | 1 | `RegWrite & ~stall`; drives `reg_file.RegWrite`. |
| mem_rdata_local | 32 | `data_memory` read output. |
| mem_rdata | 32 | `io_sel ? wb_rdat : mem_rdata_local`; feeds `writeback_mux`. |
| wb_req | 1 | `io_sel & ~wb_busy & ~wb_done`; one request pulse per IO instruction into `wb_master.i_req`. |
| wb_busy | 1 | `wb_master.o_busy`. |
| wb_done | 1 | `wb_master.o_done`, 1-cycle pulse; releases `stall`. |
| wb_err_flag | 1 | `wb_master.o_err`; qualifies `wb_done`. Observation only: nothing in the core consumes it (no trap). |
| wb_rdat | 32 | `wb_master.o_rdat`, captured read data. |
| m_cyc, m_stb, m_we | 1 | Master outputs. `m_we` is broadcast to all slaves; `m_cyc`/`m_stb` go to the interconnect only. |
| m_adr, m_dat | 32 | Master address / write data, broadcast to `wb_mac_accel` and `wb_err`. |
| ram_cyc, ram_stb | 1 | Interconnect RAM-slot outputs; declared but unconnected (RAM port stubbed: `i_ram_dat=0`, `i_ram_ack=0`). |
| mac_cyc, mac_stb | 1 | Interconnect outputs to `wb_mac_accel`. |
| err_cyc, err_stb | 1 | Interconnect outputs to `wb_err`. |
| mac_dat, err_dat | 32 | Slave read data back to the interconnect. |
| mac_ack, mac_err | 1 | `wb_mac_accel` responses (`mac_err` is always 0). |
| err_ack, err_err | 1 | `wb_err` responses (`err_ack` always 0, `err_err` = access). |
| ic_ack, ic_err | 1 | Interconnect response to `wb_master.i_wb_ack` / `i_wb_err`. |
| ic_dat | 32 | Interconnect read data to `wb_master.i_wb_dat`. |

Bus is word-only (no `SEL`): `SB`/`SH` to IO space writes a full word. An IO access costs 3 cycles (request, ACTIVE with combinational ACK, done pulse); writeback and the PC advance happen on the `wb_done` cycle.

## wb_master ports

Parameters: `ADDR_WIDTH = 32`, `DATA_WIDTH = 32`.

| Port | Dir | Width | Description |
|---|---|---|---|
| i_clk | in | 1 | Clock. |
| i_rst | in | 1 | Synchronous reset. |
| i_req | in | 1 | Start a transaction; ignored while busy. |
| i_we | in | 1 | 1 = write, 0 = read. |
| i_addr | in | ADDR_WIDTH | Byte address (`ALU_result`). |
| i_wdat | in | DATA_WIDTH | Write data (`rs2_data`). |
| o_rdat | out | DATA_WIDTH | Read data captured on ACK/ERR. |
| o_busy | out | 1 | `state != IDLE`. |
| o_done | out | 1 | 1-cycle pulse when the cycle terminates (ACK or ERR). |
| o_err | out | 1 | Qualifies `o_done`: 1 = terminated by ERR. |
| o_wb_cyc, o_wb_stb, o_wb_we | out | 1 | Registered Wishbone control. |
| o_wb_adr | out | ADDR_WIDTH | Latched address. |
| o_wb_dat | out | DATA_WIDTH | Latched write data. |
| i_wb_dat | in | DATA_WIDTH | Read data from interconnect. |
| i_wb_ack, i_wb_err | in | 1 | Terminators; either ends the cycle. |

Effective FSM is IDLE -> ACTIVE -> IDLE. A `DONE` state is declared but unreachable (ACTIVE returns straight to IDLE; the file header comment is stale).

## wb_interconnect

Ports: master side `i_wb_cyc/stb/we/adr/dat_ms`, `o_wb_dat_sm`, `o_wb_ack`, `o_wb_err`; per slave `o_*_cyc/stb`, `i_*_dat`, `i_*_ack`, plus `i_mac_err` and `i_err_err`. `i_err_ack` exists but is intentionally unused.

| Item | Equation / note |
|---|---|
| sel_ram | `adr[31:10] == 22'd0` (0x0000_0000 - 0x0000_03FF) |
| sel_mac | `adr[31:16] == 16'h1000` (0x1000_0000 - 0x1000_FFFF) |
| sel_err | `~sel_ram & ~sel_mac` (catch-all) |
| o_*_cyc / o_*_stb | `i_wb_cyc/stb & sel_*` |
| o_wb_ack | `(sel_ram ? i_ram_ack : 0) \| (sel_mac ? i_mac_ack : 0)` |
| o_wb_err | `(sel_mac ? i_mac_err : 0) \| (sel_err ? i_err_err : 0)` |
| o_wb_dat_sm | `sel_ram ? i_ram_dat : sel_mac ? i_mac_dat : i_err_dat` |
| wb_ram | Has no ERR port. |

## wb_mac_accel

Parameters: `ADDR_WIDTH = 16` (64 KB slot), `DATA_WIDTH = 32`, `BUF_AW = 12` (4096 words per buffer). Computes `acc += sum(A[i]*B[i])`, signed 32x32 -> 64, one element per clock. ACK is combinational (`o_wb_ack = access`), `o_wb_err = 0`, `o_irq = done` (left unconnected in `cpu_top_wb`).

| Offset (from 0x1000_0000) | Name | Description |
|---|---|---|
| 0x0000 - 0x3FFF | BUF_A | 4096 signed words. |
| 0x4000 - 0x7FFF | BUF_B | 4096 signed words. |
| 0x8000 | CTRL | `[0]` START, `[1]` CLR_ACC; self-clearing, reads 0. Both ignored while BUSY; START also ignored if `LEN == 0`. |
| 0x8004 | STATUS | `[0]` BUSY (RO), `[1]` DONE (sticky, write 1 to clear). |
| 0x8008 | LEN | Element count; values above 4096 clamp to 4096. Writable while idle. |
| 0x800C | ACC_LO | `acc[31:0]`, writable while idle. |
| 0x8010 | ACC_HI | `acc[63:32]`, writable while idle. |

Register page is aliased every 32 bytes (index = `offset[4:2]`); indices 5-7 read 0. Do not write buffers while BUSY.

## wb_err / wb_ram

| Module | Behaviour |
|---|---|
| wb_err | `access = cyc & stb`; `o_wb_err = access`, `o_wb_ack = 0`, `o_wb_dat = 0`. |
| wb_ram | Params `ADDR_WIDTH = 8` (256 words, 1 KB), `DATA_WIDTH = 32`, `MEM_FILE` (default `"hardware/src/core/mem/data.hex"`). Combinational ACK, no ERR port. NOT instantiated in `cpu_top_wb` (RAM port stubbed); used only by `tb_wb_integ`. |

| Macro | Value |

| WB_MAC_BASE | 32'h1000_0000 |

| WB_MAC_END | 32'h1000_FFFF |
| WB_MAC_BUFA_OFF | 16'h0000 |
| WB_MAC_BUFB_OFF | 16'h4000 |
| WB_MAC_REG_OFF | 16'h8000 |
| WB_MAC_CTRL | 32'h1000_8000 |
| WB_MAC_STATUS | 32'h1000_8004 |
| WB_MAC_LEN | 32'h1000_8008 |
| WB_MAC_ACC_LO | 32'h1000_800C |

| WB_MAC_DONE | 1 |
| WB_ERR_BASE | 32'hFFFF_0000 |
| WB_ERR_END | 32'hFFFF_FFFF |

Caveat: the `wb_defs.vh` header describes regions by top byte, and `WB_ERR_*` suggests a 0xFFFF_xxxx range. The real decode uses `adr[31:10]` (RAM) and `adr[31:16]` (MAC), and the error slave is a catch-all, so e.g. 0x0000_0800 (outside the 1 KB RAM) and 0x1001_0000 hit `wb_err`. In the SoC the low 64 KB never reaches the bus (`io_sel`), so RAM-slot addresses are unreachable there.

> Signal names follow the RTL as implemented. `branch_logic`, `jump_logic` and `imm_gen` are the real module identifiers. The final PC target is selected in `cpu_top_wb` (`jump ? jump_target : branch_target`); the PC then chooses between `target` and `pc + 4` using `branch_taken | jump1 | jump2`, unless `stall` holds it.

> Encodings (`ALUOp`, `ALUControl`, `funct3`) are defined in `control_unit.v` and `alu_control.v`; refer to the source for values. `data_memory` backs only 4097 words (16 KB) of the 64 KB local window.
